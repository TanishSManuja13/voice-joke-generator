# 🎭 Voice-Controlled Fun Generator

This project is built for the **"No Hands: The Whisper Challenge"** hackathon. It is a lightweight web application that generates funny jokes and motivational quotes entirely through **Voice Commands** (hands-free interaction).

## 🚀 Features
- **Hands-Free Control:** Speak into your microphone to trigger new jokes or quotes without touching the keyboard or mouse.
- **Modern UI:** Styled with a clean Glassmorphism dark/gradient aesthetic using HTML5 and CSS3.
- **Web Speech API:** Utilizes built-in browser speech recognition for seamless voice interaction.

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Web Speech API)

## 💻 How to Run Locally
1. Download or clone this repository to your local machine.
2. Open the `index.html` file in any modern web browser (Google Chrome is recommended).
3. Click the **"Speak to Change"** button and speak to enjoy the app!

## 🏆 Hackathon Context
Created as part of the **No Hands** challenge, emphasizing voice-first development and accessibility.
